# Professional Portrait Asset

Place your portrait photo in this directory:

- **Primary file name:** `goutam-prusty.webp` (or `goutam-prusty.jpg` / `goutam-prusty.png`)
- **Recommended dimensions:** 800 × 1000 px (4:5 portrait aspect ratio)
- **Framing:** Head and upper shoulders centered, looking toward camera
- **Optimization:** Compressed WebP under 200 KB for optimal Core Web Vitals

Once placed, the homepage hero Observatory frame automatically detects and renders the photograph within the architectural arch framing.
