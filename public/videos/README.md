# Project Demonstration Video Assets

This directory hosts demonstration video screen recordings for project case studies.

## PRJ-004: AI Engineer Command Center

- **Target WebM file:** `public/videos/prj-004-command-center-demo.webm`
- **Fallback MP4 file:** `public/videos/prj-004-command-center-demo.mp4`
- **Poster image:** `public/videos/prj-004-command-center-poster.webp`
- **Duration:** 20–30 seconds
- **Resolution:** 1080p (1920×1080) or 720p (1280×720), 16:9 aspect ratio
- **File size budget:** Ideally < 3 MB (max 5 MB)
- **Audio:** Muted / no sound
- **Playback mode:** Native HTML5 `<video controls preload="metadata">` (no autoplay)
- **Content:** Real screen recording demonstrating the working dashboard:
  1. 20-week progression matrix
  2. Spaced revision flashcard review
  3. Study session logger & journal
  4. Learning analytics & KPI charts

Once placed, the project detail page `/projects/ai-engineer-command-center/` will automatically embed the video player with controls.
